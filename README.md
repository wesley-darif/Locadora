# Locadora
Projeto pessoal para melhorar conhecimento em python


-Pretendo simular uma locadora que seja capaz de cadastrar, excluir e alterar clientes, filmes, gêneros e pedidos.
-A locadora deve ter um estoque, onde deve ser alterado a cada emprestimo/devolução.
-Terá movimentações financeiras, que deve ser exibido apenas ao dono/administrador.
